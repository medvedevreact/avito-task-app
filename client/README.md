# 🚀 AvitoTask

## 📦 Стек технологий

- **Backend**: Go
- **Frontend**: React + TypeScript
- **Forms**: React Hook Form + Zod
- **Drag & Drop**: DnD Kit
- **Уведомления**: React Hot Toast
- **Валидация**: Zod
- **Тестирование**: Jest + React Testing Library

---

## ⚙️ Установка и запуск

### 📡 Сервер

```bash
cd server
go run cmd/service/main.go
```

---

### 🖥️ Клиент

```bash
cd client
npm install
npm run dev
```

---

### 🧪 Тесты

```bash
cd client
npm run test
```

---

## 📚 Используемые библиотеки

| Библиотека                 | Назначение                     |
| -------------------------- | ------------------------------ |
| **dnd-kit**                | Drag and Drop функциональность |
| **react-hot-toast**        | Отображение уведомлений        |
| **react-hook-form**        | Удобная работа с формами       |
| **zod**                    | Валидация форм и данных        |
| **jest**                   | Unit тестирование              |
| **@testing-library/react** | Тестирование компонентов React |
